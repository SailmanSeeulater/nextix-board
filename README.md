# nextix-board

A test repository for [nexTix](https://github.com/SailmanSeeulater/nextix): tickets filed
here are worked on by a Claude agent, which opens a pull request for each one.

## Contributing

Propose a change by filing a nexTix ticket — a GitHub issue on this repository
labeled `nextix`. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to file one and
what to include.
